# Audio Utilities (`audioutils`)

## Overview
Groups user-space audio playback helpers, musical score parsers, and software synthesizer libraries for NuttX applications.

## Subdirectories & Boundaries
- `fmsynth`: [./fmsynth/README.md](./fmsynth/README.md) - Software Frequency Modulation (FM) synthesizer, operator, and ADSR envelope generator library.
- `mml_parser`: [./mml_parser/README.md](./mml_parser/README.md) - Music Macro Language (MML) score string parser.
- `nxaudio`: [./nxaudio/README.md](./nxaudio/README.md) - NuttX `/dev/audio` device playback wrapper and POSIX message queue loop helper.
