# `games`

## Overview
Groups Games (`games`) components and utilities for NuttX.

## Subdirectories & Boundaries
- `NXDoom`: [./NXDoom/README.md](./NXDoom/README.md) - Provides NXDoom (`games/NXDoom`). Play DOOM on NuttX!
- `brickmatch`: [./brickmatch/README.md](./brickmatch/README.md) - Brick-matching puzzle game (`brickmatch`) supporting LCD framebuffers (`/dev/fb0`) or WS2812 LED matrices with console key, digital joystick, gesture sensor, GPIO button, or touchscreen input.
- `cgol`: [./cgol/README.md](./cgol/README.md) - Provides Conway's Game of Life (`games/cgol`). Enable Conway's Game of Life.
- `match4`: [./match4/README.md](./match4/README.md) - Provides Match 4 Game (`games/match4`). Enable Match 4 game.
- `snake`: [./snake/README.md](./snake/README.md) - Classic Snake game (`snake`) rendered onto a WS2812 RGB LED matrix with console keyboard or GPIO directional button input.
