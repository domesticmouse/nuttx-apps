# `industry`

## Overview
Groups Industrial Applications (`industry`) components and utilities for NuttX.

## Subdirectories & Boundaries
- `abnt_codi`: [./abnt_codi/README.md](./abnt_codi/README.md) - Provides ABNT CODI Library (`industry/abnt_codi`). Enable or disable the ABNT CODI Library
- `cnc`: [./cnc/README.md](./cnc/README.md) - Groups CNC (`industry/cnc`) components and utilities for NuttX.
- `foc`: [./foc/README.md](./foc/README.md) - Provides FOC Library (`industry/foc`). Enable or disable the FOC Library
- `modbus`: [./modbus/README.md](./modbus/README.md) - Groups Modbus (`industry/modbus`) components and utilities for NuttX.
- `nxmodbus`: [./nxmodbus/README.md](./nxmodbus/README.md) - Provides NxModbus - New Modbus Stack (`industry/nxmodbus`). NxModbus is a modern Modbus stack for NuttX with multi-instance support, per-instance register callbacks, and pluggable transport
