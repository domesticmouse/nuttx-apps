# `graphics`

## Overview
Groups Graphics Support (`graphics`) components and utilities for NuttX.

## Subdirectories & Boundaries
- `ft80x`: [./ft80x/README.md](./ft80x/README.md) - Provides FTDI/BridgeTek FT80x library (`graphics/ft80x`). Enable support for the FTDI/BridgeTek FT80x library.
- `input`: [./input/README.md](./input/README.md) - Provides Monkey test (`graphics/input`). This is a simple input generator library that can be used to generate input events for testing graphics applications.
- `jpgresizetool`: [./jpgresizetool/README.md](./jpgresizetool/README.md) - Provides JPGResizeTool (`graphics/jpgresizetool`). Libjpeg JPEG resizer
- `nxglyphs`: [./nxglyphs/README.md](./nxglyphs/README.md) - Architectural grouping for `graphics/nxglyphs`, organizing `include`, `src`.
- `nxwidgets`: [./nxwidgets/README.md](./nxwidgets/README.md) - Provides NxWidgets (`graphics/nxwidgets`). Enable support for NxWidgets
- `nxwm`: [./nxwm/README.md](./nxwm/README.md) - Provides NxWM (`graphics/nxwm`). Enable support for the NuttX Tiny Window Manager (NxWM)
- `pdcurs34`: [./pdcurs34/README.md](./pdcurs34/README.md) - **Welcome to PDCurses!**
- `screenshot`: [./screenshot/README.md](./screenshot/README.md) - Provides TIFF screenshot utility (`graphics/screenshot`). Generate a NX screenshot utility based on the TIFF library.
- `slcd`: [./slcd/README.md](./slcd/README.md) - Provides Segment LCD Emulaton (`graphics/slcd`). Enable the CLcd class which implements an NX LCD simulation.
- `tiff`: [./tiff/README.md](./tiff/README.md) - Provides TIFF file generation library (`graphics/tiff`). Enable support for the TIFF file generation program.
- `twm4nx`: [./twm4nx/README.md](./twm4nx/README.md) - Provides Minimal Tom's Window Manager (TWM) for NuttX (Twm4Nx) (`graphics/twm4nx`). Enable Tom's Window Manager (TWM) for NuttX (Twm4Nx).
