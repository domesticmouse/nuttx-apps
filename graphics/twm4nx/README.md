# `graphics/twm4nx`

## Overview
Provides Minimal Tom's Window Manager (TWM) for NuttX (Twm4Nx) (`graphics/twm4nx`). Enable Tom's Window Manager (TWM) for NuttX (Twm4Nx).

## Subdirectories & Boundaries
- `apps`: [./apps/README.md](./apps/README.md) - Provides Touchscreen (`graphics/twm4nx/apps`). Enable support for the touchscreen calibration display.
- `src`: [./src/README.md](./src/README.md) - Implements `graphics/twm4nx/src` source and header components (`cbackground.cxx`, `cfonts.cxx`, `ciconmgr.cxx`, `ciconwidget.cxx` and 10 more files) in the NuttX application tree.
