# OpenH264 Compatibility Headers (`videoutils/openh264/include`)

## Overview
Groups compatibility system header overrides used when building the OpenH264 library on NuttX.

## Subdirectories & Boundaries
- `sys`: [./sys/README.md](./sys/README.md) - Compatibility `sys/sysctl.h` stub macros (`sysctl`, `sysctlbyname`, `sysctlnametomib`) for OpenH264 builds.
