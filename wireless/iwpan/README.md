# `wireless/iwpan`

## Overview
Provides IEEE 802.15.4 Command Line Tool (`wireless/iwpan`). IWPAN is a tool similar to wapi and inspired by iwpan on Linux that can be used to manage 802.15.4 PAN.

## Subdirectories & Boundaries
- `src`: [./src/README.md](./src/README.md) - Implements `wireless/iwpan/src` source and header components (`iwpan.c`) in the NuttX application tree.
