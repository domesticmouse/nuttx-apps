# `wireless/ieee802154`

## Overview
Groups IEEE 802.15.4 applications (`wireless/ieee802154`) components and utilities for NuttX.

## Subdirectories & Boundaries
- `i8sak`: [./i8sak/README.md](./i8sak/README.md) - Provides IEEE 802.15.4 Swiss Army Knife (`wireless/ieee802154/i8sak`). Enable the IEEE 802.15.4 Swiss Army Knife
- `i8shark`: [./i8shark/README.md](./i8shark/README.md) - Provides IEEE 802.15.4 Wireshark adapter (`wireless/ieee802154/i8shark`). The default path to MAC character driver. Default: /dev/ieee0
- `libmac`: [./libmac/README.md](./libmac/README.md) - Provides IEEE 802.15.4 MAC library routines (`wireless/ieee802154/libmac`). Some MAC library routines for ieee 802.15.4 apps
- `libutils`: [./libutils/README.md](./libutils/README.md) - Provides Common IEEE 802.15.4 library routines (`wireless/ieee802154/libutils`). Some common library routines for ieee 802.15.4 apps
