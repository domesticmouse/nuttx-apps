# `wireless/bluetooth`

## Overview
Groups Bluetooth applications (`wireless/bluetooth`) components and utilities for NuttX.

## Subdirectories & Boundaries
- `btsak`: [./btsak/README.md](./btsak/README.md) - Provides Bluetooth Swiss Army Knife (`wireless/bluetooth/btsak`). Enable the Bluetooth Swiss Army Knife
- `nimble`: [./nimble/README.md](./nimble/README.md) - Provides Apache NimBLE (BLE host-layer) (`wireless/bluetooth/nimble`). Enable Apache NimBLE Bluetooth Low Energy host-layer stack.
