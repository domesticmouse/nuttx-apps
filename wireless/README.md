# `wireless`

## Overview
Groups Wireless Libraries and NSH Add-Ons (`wireless`) components and utilities for NuttX.

## Subdirectories & Boundaries
- `bluetooth`: [./bluetooth/README.md](./bluetooth/README.md) - Groups Bluetooth applications (`wireless/bluetooth`) components and utilities for NuttX.
- `gs2200m`: [./gs2200m/README.md](./gs2200m/README.md) - Provides Telit GS2200M usrsock daemon (`wireless/gs2200m`). Enable support for the gs2200m usrsock daemon
- `ieee802154`: [./ieee802154/README.md](./ieee802154/README.md) - Groups IEEE 802.15.4 applications (`wireless/ieee802154`) components and utilities for NuttX.
- `iwpan`: [./iwpan/README.md](./iwpan/README.md) - Provides IEEE 802.15.4 Command Line Tool (`wireless/iwpan`). IWPAN is a tool similar to wapi and inspired by iwpan on Linux that can be used to manage 802.15.4 PAN.
- `lora_pkt_fwd`: [./lora_pkt_fwd/README.md](./lora_pkt_fwd/README.md) - Provides LoRaWAN Semtech UDP packet forwarder (`wireless/lora_pkt_fwd`). Forwards the packets received by a LoRa concentrator to a LoRaWAN network server using the Semtech UDP protocol version 2, and turns
- `wapi`: [./wapi/README.md](./wapi/README.md) - Implements `wireless/wapi` contracts and interfaces in the NuttX application tree.
