# Built-In Applications (`builtin`)

## Overview
Provides the registry and execution runtime for NuttX built-in applications. At build time, `.bdat` and `.pdat` metadata files generated by configured applications are aggregated into `builtin_list.h` and `builtin_proto.h` to populate the global built-in application table `g_builtins`, which `exec_builtin()` resolves to spawn tasks or processes by name.

## Interface
- `[apps/builtin/builtin_list.c:g_builtins]`: Global array of `struct builtin_s` descriptors mapping built-in application names, priorities, stack sizes, and main entry points.
- `[apps/builtin/builtin_list.c:g_builtin_count]`: Total count of registered built-in application entries in `g_builtins`.
- `[apps/builtin/exec_builtin.c:exec_builtin]`: Spawns a registered built-in application by name with optional argument vectors, file redirection paths, and file actions.

## Invariants
- `[apps/builtin/builtin_list.c:g_builtins]`: Always terminated by a null-sentinel entry (`{ NULL, 0, 0, 0, 0, 0, 0 }` when `CONFIG_SCHED_USER_IDENTITY` is defined, or `{ NULL, 0, 0, 0 }` otherwise).
- `[apps/builtin/exec_builtin.c:exec_builtin]`: Requires `appname` to resolve to a valid index via `builtin_isavail(appname) >= 0` and a non-NULL `struct builtin_s` via `builtin_for_index(index)`, otherwise failing with `ENOENT`.

## Side Effects
- `[apps/builtin/exec_builtin.c:exec_builtin]`: Configures task priority, stack size, scheduling policy (`SCHED_RR` when `CONFIG_RR_INTERVAL > 0`), and file redirection/`dup2` actions, then spawns a new task or process via `posix_spawn()` (if `CONFIG_LIBC_EXECFUNCS` is enabled) or `task_spawn()` and sets `errno` on failure.
- `[apps/builtin/Makefile:builtin_list.h]` and `[apps/builtin/Makefile:builtin_proto.h]`: Aggregate `*.bdat` and `*.pdat` files from the registry directory at build time to generate built-in application table entries and prototypes.
