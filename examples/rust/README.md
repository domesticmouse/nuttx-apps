# rust

## Overview
Intermediate grouping directory for `rust`, organizing submodules: baremetal, hello, slint.

## Subdirectories & Boundaries
- **baremetal**: [`./baremetal/README.md`](./baremetal/README.md) - "Hello, Rust!" example (`rust/baremetal`). Enable the "Hello, Rust!" example to show how to build and run a baremetal Rust application with rustc.
- **hello**: [`./hello/README.md`](./hello/README.md) - "Hello, Rust!" example with Cargo (`rust/hello`). Enable the "Hello, Rust!" example using Cargo to build.
- **slint**: [`./slint/README.md`](./slint/README.md) - Slint Basic Example (`rust/slint`). Enable the basic Slint example.
