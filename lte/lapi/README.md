# `lte/lapi`

## Overview
LTE Application Programming Interface (`lapi`) client library (`CONFIG_LTE_LAPI`) providing synchronous and asynchronous APIs for modem power, PDN activation, SIM/PIN, radio quality, eDRX/PSM power saving, firmware updates, and LwM2M over `usrsock`.

## Subdirectories & Boundaries
- `src`: [./src/README.md](./src/README.md) - Implements `lte/lapi/src` source and header components (`lapi_dbg.h`, `lapi_evt.c`, `lapi_firmware.c`, `lapi_log.c` and 9 more files) in the NuttX application tree.
