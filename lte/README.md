# `lte`

## Overview
Groups LTE Libraries and NSH Add-Ons (`lte`) components and utilities for NuttX.

## Subdirectories & Boundaries
- `alt1250`: [./alt1250/README.md](./alt1250/README.md) - Provides ALT1250 usrsock daemon (`lte/alt1250`). Enable support for the alt1250 usrsock daemon
- `lapi`: [./lapi/README.md](./lapi/README.md) - LTE Application Programming Interface (`lapi`) client library (`CONFIG_LTE_LAPI`) providing synchronous and asynchronous APIs for modem power, PDN activation, SIM/PIN, radio quality, eDRX/PSM power saving, firmware updates, and LwM2M over `usrsock`.
